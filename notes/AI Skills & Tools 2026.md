## Pocock Skills

- Vercels https://www.skills.sh/ - `npx skills@latest add mattpocock/skills`
  - https://github.com/mattpocock/skills/tree/main
  - skills tool has universal support for a lot of tools

Vercel want's to install `find-skills`

```
Install the find-skills skill? It helps your agent discover and suggest skills. You can install it later with: npx skills add vercel-labs/skills@find-skills
```

Usage in Open Code: 

```
Ways to use it:

Mention it: @grill-me I want to add caching to the API layer — or @grill-with-docs ... if you want docs produced.
Skip the alias and use the engine directly: @grilling <topic> (identical result, one less hop).
Plain language also works, because grilling is model-invocable and its description lists "grill" as a trigger: "grill me on X", "stress-test this plan", "poke holes in this design".
```
